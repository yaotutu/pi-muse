# Agent 协作指南

本文是 pi-muse 工作区开发工作的必读协作规范，集中维护执行方式、模型使用、任务单、执行入口、失败语义、日志边界与交付闭环。全局安全、数据、进程、提交和真实测试底线见[根规则](../../AGENTS.md)。本文不维护业务架构、API 或测试细节，也不绑定任何具体模型产品或 CLI 工具。

## 执行方式与模型使用

- 当前由本会话主模型直接执行全部开发工作：需求澄清、产品与架构取舍、安全与协议决策、调查、实现、UI、回归测试、文档、关键 diff 审查、集成验收、进程协调、项目地图更新与本地提交汇报。不另设“子经理”，不把这些职责转交给其他执行者，也不因无法委派而限制为协调和少量修改。
- 不调用 subagent，也不通过任何外部 CLI 或工具启动、续派替代执行者；不以只读调查、测试、截图或审查为由绕过。只有用户重新明确授权后才恢复委派；工具可用性或额度变化不等于重新授权。
- 按业务模块串行推进，不为并行而委派。跨端任务先确定契约、失败语义和依赖，再直接实现；共享契约或共享文件串行修改，不覆盖其他工作区或他人改动。
- 开发所用模型由用户在会话层面决定。Agent 不自动切换模型、不轮换别名、不探测额度，也不修改全局模型、代理或工具配置；主模型遇到限流、权限或不支持的参数时如实报告，不反复猜参数，不自动启用备用模型或执行者。
- 开发模型与产品业务模型是两回事：本文只约束开发 Agent 的执行方式，不改变 Pi Muse 产品内的模型配置，也不撤销项目已有的真实业务模型测试及费用授权。

## 任务单

主 Agent 直接执行时同样先明确目标、范围、非目标、依赖和验收，不必为此新增任务文档。只有用户重新授权委派后，才在派单正文包含以下字段；小任务可在同一段落紧凑表达。

```text
目标：用户可观察的变化
范围/所有权：允许修改的文件/模块、共享文件协调方式
非目标：本次明确不做的事
依据/依赖：契约、必读文档、已确定设计与前置任务
约束：权限、数据、进程、发布、不可自动重试等边界
验收：可观察行为、异常与迟到场景、验证命令和环境
交付：修改位置、实际验证结果、风险与未验证项
```

- 验收必须描述实际行为与版本范围，例如“旧响应不得污染新智能体”“结果未明不能重发”“读取失败不能显示为空列表”；不能只写“功能正常”或“测试通过”。
- 派单同时传递真实后端与真实外部模型要求、费用长期授权、隔离数据边界和共享工作区提醒。执行者发现跨范围、协议、安全或权限问题时停止并携证据返回，不自行扩大写集。
- 恢复委派后，派单须明确禁止执行者递归委派，执行者不得覆盖或回滚他人改动。

## 执行入口

- 当前只使用本会话主模型直接执行。用户重新明确授权委派后，可使用当时可用的内置 subagent 工具或外部 CLI 启动、续派执行者；具体用法以所用工具当时的文档为准，本文不绑定具体产品、命令或参数。
- 使用任何委派入口时，按工具实际 schema 或文档构造参数：可选参数未使用时省略，不猜参数或以空值代替未提供；不绕过审批、不扩大权限、不修改全局配置。
- 中断或结果未明时先检查进程状态、文件 diff 与已完成步骤，不直接重放写操作。恢复委派后还须记录入口、请求模型、会话标识、退出码与结果；不能确认前一执行者结束并释放写集时，不启动接替写入者。

## 失败与日志

- 区分调用失败、执行失败和验收失败。调用未启动不得记为执行失败；执行者完成也不等于主 Agent 验收通过。不反复重发相同无效参数，不盲目多层重试或转包。
- 只读探测可安全重试一次；写任务超时、断线或结果未明时，先核对状态与 diff，不得直接重放整张任务单。模型限流、路由失败或不支持参数时如实报告，不自动切换模型或启用执行者。
- 禁止整体输出 `env`、`printenv`、凭据配置或开发工具密钥。确需核对环境时，只检查已知变量存在性或非敏感状态；socket/IPC 被沙箱拒绝或权限阻塞时停止相应探测并返回主 Agent，不倾倒环境或扩大权限。
- 不把密钥、token、用户已有会话内容、用户实例数据或完整日志写入交付、文档、项目地图或验收记录。隔离测试数据与必要错误证据先脱敏，只保留验收和定位所需内容。

## 闭环

1. 需求与写集 → 必要调查与契约确认 → 主 Agent 直接实现及回归测试 → 审查 diff → 双端集成验收 → 模块内整理与必要复验 → 更新项目地图 → 对应子仓库本地提交并汇报。
2. 主 Agent 验收时检查关键实现、实际命令结果、真实验收证据和未验范围，不以执行者结论代替独立核查。自动化、真实接口、真实模型与原生运行分别记录，历史通过不算本次通过。
3. 文档-only 变更只检查差异、引用、命名与规则一致性；涉及手册构建、导航或用户可见行为时另按[Agent 文档编写指南](agent-documentation-guide.md)完成对应验证。
