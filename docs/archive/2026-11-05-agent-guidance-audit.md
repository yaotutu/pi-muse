## 保留和未擅自决策的事项

- 不放松产品 bash 禁止、完整差异人工审批/版本绑定、Key 隔离、SSRF/文件路径限制、真实数据与生产保护。
- 保留开发进程启停、真实模型测试费用和已验收模块本地 commit 的长期授权；不扩展到 push、版本、发布、CI 或全局配置。
- 本地 unit/integration/E2E 与移动端 test 存在模拟模型/fixture 是现存事实；根规则原“所有测试都必须真实”与现有门禁并非同一层。明确分别报告，并保留真实验收不能被替代的要求；没有迁移测试或宣称模拟测试满足真实模型要求。是否重写整套本地测试是独立开发任务，不在本次文档整理中实施。
- 浏览器密码暴露/脱敏、旧数据迁移和品牌原生接入等产品或安全取舍不因适配 Claude 自动调整；可能冲突时留给专项核对。
- 不宣称所有用户手册业务描述已逐项验真；仅同步本次开发入口，并构建现有中英文站点。历史界面截图、旧原生脚本与公开发布能力仍需按后续实际任务核对。
- 根目录没有 Git，工作区 CLAUDE.md/AGENTS.md/project-map.md 和本机旧地图仅存本地，不随子仓库提交；不初始化根仓库。
