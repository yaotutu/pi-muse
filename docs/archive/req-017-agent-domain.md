# REQ-017：统一 Agent 模型

## 本批范围

- 将 Space 业务概念统一为 Agent／智能体，不保留 Space/Thread 路由、字段、导出别名或双轨读取器。
- 新闻与短信是完整 Agent；独立阅读、RSS、短信采集与后台分析是附加业务扩展。不是另一类受限的核心执行主体。
- 保留稳定 ID、PI 会话与历史、指令、技能覆盖、私有文件、原有按需记忆检索、任务与 Dream，以及群／私聊／讨论隔离。实例身份与长期记忆仍共享，不新增独立账号、人设库或另一份历史。
- 本批不实现顶部头像条与左右滑动导航，不改其他工作树，不迁移真实实例数据，不 push 或发布。

## 实现边界

- `features/agents` 统一目录投影与创建、重置、删除生命周期，HTTP 不直接级联操作存储。文件操作由 storage adapter 承接。
- `/api/agents` 是唯一目录，`extensions` 声明 news/sms 附加业务。通信工具的发现动作使用同一投影；移除单独成员目录与重复 HTTP 通信目录。
- 智能体通信使用 `agent` 工具和 Agent 字段；请求在目标独立讨论执行，回复沿原调用返回。群无 @ 仍只交 main，显式 @ 只交所选智能体，不广播，也不合并私聊。
- 实例身份资料、Dream 概览和运行快照不与目录混用。当前移动端和自有 Web 同步消费新契约。
- 新闻、短信同样可聊天、配置指令与技能、读写自己文件、使用 Dream、拥有任务和承接通知。通知绑定接受任意已存在智能体，不启用短信监听，不复制数据。内置智能体不能删除仍是业务生命周期约束。
- 私有文件使用 `workspace/agents/<agentId>/`；检测旧 `workspace/threads/` 时在初始化写入前拒绝启动，原字节保留。持久化字段、用途标题与 PI 通信 marker 也有变化，不能只重命名目录。没有运行时旧读取器或隐式转换；真实数据转换须另行确认。
- 人工差异审批、文件版本绑定、鉴权、凭据保护、SSRF 和错误脱敏保持原安全边界。

## 本批证据

隔离证据在工作树 `ui-previews/agent-refactor/`，不将临时状态、凭据或日志纳入仓库。

- 当前移动端 HTTP 客户端真实消费目录、配置、文件、聊天与群协议；主、新闻、短信和自定义智能体独立聊天，专属指令实际进入模型。
- main → 短信、短信 → main 的真实模型独立讨论及连续追问；不改变双方私聊历史。模型实际执行新 `agent` 工具。
- 真实模型提出文件写入审批；客户端核对 Agent 归属和完整内容后拒绝，文件未提交。
- 合成短信由真实后台模型处理，通知送往新闻智能体，并在群投影中保留短信来源及真实承接方。结束后关闭隔离短信处理、恢复 main 绑定；未申请 Android 短信权限。
- 当前代码重启后保留智能体、指令、文件和通知配置，并再次实际调用外部模型。20 次真实外部请求有透明代理记录；不以夹具或模型自述替代状态断言。
- Android 原生操作覆盖显式 @ 发送、成员主页、当前智能体设置、规则、技能、扩展配置、新闻阅读，以及私有文件原文编辑与完整预览确认保存；320dp／1.5 字号进入设置后恢复默认显示。自有 Web 实际渲染真实 `agent` 工具结果及刷新历史，当前 `/docs` 有浏览器截图。内置 Browser 连接失败后使用独立无用户资料的本机 Chrome 验证。

## 顶部头像导航（2026-11-04）

后续导航模块已接入统一 Agent 底座：默认仍是群聊，顶部头像直接切换群与各智能体私聊；再次点击当前头像或长按头像进入主页。消息阅读区支持相邻左右切换，首尾不循环，不接管纵向阅读、输入栏、二级表单或代码／表格横向滚动。群信息与当前智能体设置保持各自入口，添加智能体和全局设置收进群信息；新闻阅读仍从新闻主页进入。

移动端删除旧会话列表、摘要投影与浮动聊天顶栏，不保留第二套入口；会话所有者持续挂载。当前 lint、typecheck 和 699 项测试通过。隔离当前后端使用 4 次真实外部模型请求验证默认／显式群目标、私聊隔离，以及 Android 单次发送后切换页面仍完成原回复。代理时间戳确认切换确实发生在外部请求结束前；文件草稿未提交、短信保持关闭。

Android 原生覆盖头像点击、正反滑动与边界、三份独立草稿、群／私聊设置、新闻与 RSS 返回、文件草稿对点击及滑动的保护、真实创建、长头像栏自动露出当前项、删除当前成员后的回退、三主题及 320dp／1.5 字号。驱动曾因错误控件名称、空输入占位符、文本注入和启动等待失败；草稿检查也被开发热重载干扰，均分段回读后重测，不将失败记为首次通过。

本批同步六对中英文手册及移动开发／主题指南。当前 `/docs` 与两种语言手册有实际浏览器渲染证据，手册生产构建通过；内置 Browser 缺失运行模块，使用不加载用户资料的独立 Chrome 验证。证据位于工作树 `ui-previews/avatar-navigation/`，不把临时实例、凭据或日志纳入仓库。本批不修改服务端业务协议，不新增原生依赖，不代表发布 APK；未验 iOS、真实手机短信采集或新 RSS 外网抓取。

## 聚合入口命名（2026-11-04）

顶部聚合入口改称「全部」，原群信息页显示「成员与设置」，成员标题、返回、读屏、连接错误和重置／删除范围提示同步更新。此次仅修改显示文案，不更名内部 `group` 路由或 `/api/group`，不改变默认 main／显式单一目标及独立上下文。手册强调「全部」是聚合展示，不是向所有智能体广播。

本批移动端 lint、typecheck 和 700 项测试通过；隔离当前后端的 2 次真实外部模型请求验证默认 main 与定向短信各完成一次，所有私聊历史保持不变，短信采集关闭。Android 在消息正文区实际完成左滑、右滑、首尾边界与纵向阅读检查，验证当前智能体设置、改名后成员管理／全局设置及逐层返回；不把头像栏滑动当作正文手势证据。

五对中英文手册同步，生产构建、配对锚点与本地引用检查通过；当前 `/docs` 和双语手册均有独立 Chrome 渲染证据。工作树证据位于 `ui-previews/all-chat-labels/`。没有修改服务端业务协议、真实实例数据、主题或原生依赖；未新建 APK、验证 iOS、push 或发布。

## 头像操作与设置收敛（2026-11-04）

单击顶部头像只切换聊天，已选头像单击无额外动作；长按「全部」直接进入全局设置，长按智能体直接进入该智能体设置。聊天右上角、成员主页和「成员与设置」中间页已删除，不保留兼容路由。消息中的成员头像直接打开其设置。添加、删除统一放在全局设置的「智能体管理」，重置仍在各智能体的会话管理中；新闻阅读、RSS 与短信扩展设置保留实际返回来源。

设置检查对象与聊天所有者分离：文件、规则、技能和动态跟随检查对象，原聊天的草稿、阅读位置与执行所有者保持挂载。检查设置后返回原来的「全部」或私聊；从管理页进入则返回管理页。创建成功只打开新智能体设置，不抢走原聊天；删除当前私聊对象才让后续返回落到「全部」，删除其他对象保留原聊天。删除结果未明先读目录核对，不自动重发；检查对象之间切换仍保护文件草稿和未明写入。

原生走查发现长按立即卸载触摸目标会吞掉新页面第一次点击，改为松手后跳页；流式更新繁忙时长按计时器及 press-out 可能晚到，单击和松手路径共同按原生触摸时长判定，避免长按误切聊天。最终版本 lint、typecheck 与 704 项移动测试通过。隔离当前后端有 7 次完成的真实外部模型请求：默认 main 与显式短信目标各一次，5 次原生私聊请求逐一回读确认只接收一次；短信私聊与「全部」保持原样，短信采集关闭。最终原生截图帧在外部请求结束前已显示短信设置，返回仍是 Muse 私聊且回复成功，未取消执行。

Android 同轮覆盖单击／已选无操作、长按设置与首次返回、正文左右滑动、原私聊草稿、新闻阅读／RSS、短信设置／动态、真实创建／取消删除／删除其他／删除当前、文件与规则草稿、三主题和 320dp／1.5 字号；触摸修复后另复验最终导航及真实生成中进入设置。驱动曾因控件命名、UIAutomator 等待隐藏流式页面 idle、过早读取页面和运行状态枚举假设失败；均先回读，不盲目重发已提交请求，不把这些尝试记为首次成功。
