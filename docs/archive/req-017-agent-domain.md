# REQ-017：统一 Agent 模型

## 本批范围

- 将 Space 业务概念统一为 Agent／智能体，不保留 Space/Thread 路由、字段、导出别名或双轨读取器。
- 新闻与短信是完整 Agent；独立阅读、RSS、短信采集与后台分析是附加业务扩展。不是另一类受限的核心执行主体。
- 保留稳定 ID、PI 会话与历史、指令、技能覆盖、私有文件、原有按需记忆检索、任务与 Dream，以及群／私聊／讨论隔离。实例身份与长期记忆仍共享，不新增独立账号、人设库或另一份历史。
- 本批不实现顶部头像条与左右滑动导航，不改其他工作树，不迁移真实实例数据，不 push 或发布。

## 实现边界

- `features/agents` 统一目录投影与创建、重置、删除生命周期，HTTP 不直接级联操作存储。文件操作由 storage adapter 承接。
- `/api/agents` 是唯一目录，`extensions` 声明 news/sms 附加业务。通信工具的发现动作使用同一投影；移除单独成员目录与重复 HTTP 通信目录。
- 智能体通信使用 `agent` 工具和 Agent 字段；请求在目标独立讨论执行，回复沿原调用返回。群无 @ 仍只交 main，显式 @ 只交所选智能体，不广播，也不合并私聊。
- 实例身份资料、Dream 概览和运行快照不与目录混用。当前移动端和自有 Web 同步消费新契约。
- 新闻、短信同样可聊天、配置指令与技能、读写自己文件、使用 Dream、拥有任务和承接通知。通知绑定接受任意已存在智能体，不启用短信监听，不复制数据。内置智能体不能删除仍是业务生命周期约束。
- 私有文件使用 `workspace/agents/<agentId>/`；检测旧 `workspace/threads/` 时在初始化写入前拒绝启动，原字节保留。持久化字段、用途标题与 PI 通信 marker 也有变化，不能只重命名目录。没有运行时旧读取器或隐式转换；真实数据转换须另行确认。
- 人工差异审批、文件版本绑定、鉴权、凭据保护、SSRF 和错误脱敏保持原安全边界。

## 本批证据

隔离证据在工作树 `ui-previews/agent-refactor/`，不将临时状态、凭据或日志纳入仓库。

- 当前移动端 HTTP 客户端真实消费目录、配置、文件、聊天与群协议；主、新闻、短信和自定义智能体独立聊天，专属指令实际进入模型。
- main → 短信、短信 → main 的真实模型独立讨论及连续追问；不改变双方私聊历史。模型实际执行新 `agent` 工具。
- 真实模型提出文件写入审批；客户端核对 Agent 归属和完整内容后拒绝，文件未提交。
- 合成短信由真实后台模型处理，通知送往新闻智能体，并在群投影中保留短信来源及真实承接方。结束后关闭隔离短信处理、恢复 main 绑定；未申请 Android 短信权限。
- 当前代码重启后保留智能体、指令、文件和通知配置，并再次实际调用外部模型。20 次真实外部请求有透明代理记录；不以夹具或模型自述替代状态断言。
- Android 原生操作覆盖显式 @ 发送、成员主页、当前智能体设置、规则、技能、扩展配置、新闻阅读，以及私有文件原文编辑与完整预览确认保存；320dp／1.5 字号进入设置后恢复默认显示。自有 Web 实际渲染真实 `agent` 工具结果及刷新历史，当前 `/docs` 有浏览器截图。内置 Browser 连接失败后使用独立无用户资料的本机 Chrome 验证。
