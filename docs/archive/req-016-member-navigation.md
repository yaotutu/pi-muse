# REQ-016 成员式导航与独立私聊首批验收

日期：2026-11-02。服务端与移动端分别在独立 `member-chat` 分支及 worktree 开发；本记录不代表发布，也不代表整个 REQ-016 已完成。

## 本批范围

- 既有 Space 只读投影成成员目录，不新增联系人存储，不迁移真实数据。
- 消息、新闻、成员成为底部主入口；消息行进入私聊，头像先进入成员主页，成员页点击行也进入主页。移除旧空间抽屉及边缘滑动切换。
- 成员主页收敛发消息、文件、规则、技能、会话管理与动态；新闻和短信各自拥有功能设置，全局设置从列表顶部进入。
- 新闻和短信支持独立私聊，规则、文件、会话上下文仍归对应 Space；后台通知绑定默认 main，可改为已建立普通空间，不随当前私聊变化。
- 打开成员目录或私聊不自动启用短信后台处理，也不申请系统短信权限；文件保存继续完整预览、人工确认。

- 当前移动端 lint、typecheck 与 661 项测试通过；中英文手册构建通过。
- 独立数据目录中的当前源码后端真实调用外部模型：短信私聊在后台关闭时查询自己的短信；新闻私聊无短信上下文；main 通过既有空间通信请求短信成员处理并收到结果，短信原私聊历史不被独立讨论追加。
- 运行时 `/docs` 由隔离 Chrome 实际渲染，成员目录端点可见，保留 DOM 与截图证据。未使用用户浏览器资料。

- 当前移动端 lint、typecheck 与 664 项回归全部通过；中英文手册构建、六个变更页面的本地链接与配对锚点检查通过。最初回归有一个旧动态按钮选择器断言失败，按新入口更新后完整重跑通过。
