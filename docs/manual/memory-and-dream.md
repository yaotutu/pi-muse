# 长期记忆与 Dream

长期记忆、SOUL/USER、助手指令与 Dream 都是实例全局内容，聊天正文按会话各自隔离。本文按当前服务端与客户端源码整理；实际界面请核对安装的 Release 版本。

## 前提 {#prerequisites}

连接可访问的匹配版本服务端。浏览和管理记忆无需模型；Dream 整理需要配置可用外部模型。

## 管理长期记忆 {#manage-long-term-memories}

在设置的长期记忆页面读取、关键词搜索、新增、编辑或删除。最多保存 500 条，每条 1–2000 字符；满额拒绝新增，不静默丢弃旧内容。搜索按关键词子串忽略大小写匹配。

记忆以纯文本保存在 `state/assistant/memory.md`，每条一行并带稳定 id，可以直接用编辑器查看或修改；工具的修改与删除仍按 id 精确命中。文件格式损坏时服务端明确报错，不会当作空库或静默丢弃条目。

删除不可撤销，影响所有会话而不删除聊天正文。不要存储密码、Key、token 或其他秘密。写入结果未明先读取全部记忆核对，不自动重试；读取失败不等于空库。

## 记忆与资料边界 {#memory-and-profile-boundaries}

- USER、SOUL、身份与长期记忆全局一份。SOUL/USER 每轮重读；记忆按需检索，不每轮全量注入。
- 助手指令和技能开关由各聊天会话共用。短信保存自己的偏好。
- 工作区只有一个根，所有会话共享。会话历史相互隔离，不因文件共享而合并。
- 反馈记录本身不启动 Dream、模型或训练。后台信息轮可显式读取有界的 main 当前反馈例证。

## 配置 Dream {#configure-dream}

Dream 只有一个全局启用开关；整理使用的系统提示词与安全硬规则内置在服务端仓库 `prompts/dream/` 中，不支持在数据目录覆盖或从设置页编辑。开关状态控制后续周期整理与按需手动整理，关闭只影响后续执行，不回滚已有写入。全局与领域指令、人设、技能都不能扩大整理轮工具权限。

后台固定每两小时检查现有会话，新消息按各来源游标读取，忙会话跳过。整理轮读取展开后的工作区托管文档（包含通过[顶部 Frontmatter `include:`](instructions.md#frontmatter-include) 引入的子文件）进行去重，但绝不覆写拆分子文件。

整理轮只开放结构化建议提交，不提供文件、网络、shell、委派或任意配置工具。外部内容是不可信数据；不能保存凭据、把助手猜测当用户事实或修改权限。

## 手动整理 {#run-dream-manually}

先调整并保存启用状态（或直接保持开启），再请求立即整理。服务端逐会话处理，同一时刻只接纳一个整理流程；不自动重试模型。没有新消息时不产生模型请求。

- completed：本次来源整轮成功，才推进对应游标。
- partial：部分目标/建议已写入但存在失败，不推进游标；已完成写入不回滚。
- failed：失败或启动时校准的中断状态；不能仅凭状态推断此前从未写入。

整理按新消息提取，带有界重叠上下文用于理解。USER、SOUL、助手指令与记忆都是全局目标。资料和助手指令建议一律等待确认，应用时基于原始文件（保留文件顶部 `include:` 等 Frontmatter）在末尾去重追加，并核对读取版本避免覆盖并发编辑。自动编辑或删除既有记忆时核对条目版本，并发修改的条目保留最新内容。

离开页面或客户端超时不证明服务端已取消。先回读最近结果和目标内容再决定是否重新整理。服务关闭取消在途模型，重启校准 running 为 failed，不续跑。

## 处理待决建议 {#resolve-dream-suggestions}

待决项全局最多保留 50 条去重建议，并保留来源会话。待决项满额时，整理会保留受影响的来源游标，处理部分建议后可继续整理。应用前核对完整正文、原因、来源与选定目标；可选择 USER、SOUL、助手指令或新增记忆，也可明确忽略。

建议来源用于溯源。应用到助手指令或资料后影响所有会话。忽略仅移除建议，不删除聊天。结果未明先回读列表和目标，不自动重发。

## 重置与删除影响 {#dream-reset-and-delete}

会话重置/删除不删除全局 Dream 配置、已写入资料或记忆。删掉来源后仍可核对和处理全局待决项。会话历史与反馈的不可恢复范围见[会话管理](conversations-and-agents.md#reset-and-delete-sessions)。

## 限制与故障 {#limits-and-failures}

模型失败、无效建议、并发修改、满额记忆或关闭会导致失败/部分完成；不自动回滚或重试。作用域分类依赖模型理解，服务端强制权限、工具与版本边界，但不能证明现实事实必然适用于所有话题。写入从后续轮次生效，不改已生成聊天。
