# 长期记忆与 Dream

长期记忆、SOUL/USER 和 Dream 是实例全局内容。聊天正文与会话指令仍分别属于各会话。本文描述服务端当前语义；原生客户端与真实模型链路仍待本轮统一验收，请核对安装版本。

## 前提 {#prerequisites}

连接可访问的匹配版本服务端。浏览和管理记忆无需模型；Dream 整理需要配置可用外部模型。

## 管理长期记忆 {#manage-long-term-memories}

在设置的长期记忆页面读取、关键词搜索、新增、编辑或删除。最多保存 500 条，每条 1–2000 字符；满额拒绝新增，不静默丢弃旧内容。搜索按关键词子串忽略大小写匹配。

删除不可撤销，影响所有会话而不删除聊天正文。不要存储密码、Key、token 或其他秘密。写入结果未明先读取全部记忆核对，不自动重试；读取失败不等于空库。

## 记忆与资料边界 {#memory-and-profile-boundaries}

- USER、SOUL、身份与长期记忆全局一份。SOUL/USER 每轮重读；记忆按需检索，不每轮全量注入。
- 每个会话的 INSTRUCTIONS 和技能开关独立；main 指令同时指导新闻/短信偏好。
- 工作区只有一个根，所有会话共享。会话历史相互隔离，不因文件共享而合并。
- 反馈记录本身不启动 Dream、模型或训练。后台信息轮可显式读取有界的 main 当前反馈例证。

## 配置 Dream {#configure-dream}

Dream 只有一个全局启用开关和一份全局提示词，配置在 profile/DREAM.md。没有逐会话开关、继承关系或补充提示词。提示词最多 20,000 字符，保存空串回退到内置默认。

后台固定每两小时检查现有会话，新消息按各来源游标读取，忙会话跳过。关闭只影响后续周期检查，不回滚已有写入。全局提示词、会话规则和技能都不能扩大整理轮工具权限。

整理轮只开放结构化建议提交，不提供文件、网络、shell、委派或任意配置工具。外部内容是不可信数据；不能保存凭据、把助手猜测当用户事实或修改权限。

## 手动整理 {#run-dream-manually}

先保存或明确放弃配置草稿，再请求立即整理。服务端逐会话处理，同一时刻只接纳一个整理流程；不自动重试模型。没有新消息时不产生模型请求。

- completed：本次来源整轮成功，才推进对应游标。
- partial：部分目标/建议已写入但存在失败，不推进游标；已完成写入不回滚。
- failed：失败或启动时校准的中断状态；不能仅凭状态推断此前从未写入。

整理按新消息提取，带有界重叠上下文用于理解。USER/SOUL/记忆是全局目标；非 main 来源的全局资料建议需人工确认。来源用途导致的规则仅写该来源 INSTRUCTIONS；写前核对读取版本与用途，不覆盖用户并发改动。既有记忆的编辑/删除需准确 id，不能把不确定编辑转成新增。

离开页面或客户端超时不证明服务端已取消。先回读最近结果和目标内容再决定是否重新整理。服务关闭取消在途模型，重启校准 running 为 failed，不续跑。

## 处理待决建议 {#resolve-dream-suggestions}

待决项全局最多保留 50 条去重建议，并保留来源会话。应用前核对完整正文、原因、来源与选定目标；可选择 USER、SOUL、来源规则或新增记忆，也可明确忽略。

应用到规则使用建议来源，不使用当前浏览会话；来源已删除不能被重建。改选全局目标会影响所有会话。忽略仅移除建议，不删除聊天。结果未明先回读列表和目标，不自动重发。

## 重置与删除影响 {#dream-reset-and-delete}

会话重置/删除不删除全局 Dream 配置、已写入资料或记忆。已删除来源不能接受新的指令建议；全局待决项应人工核对后忽略或明确改选有效目标。会话历史与反馈的不可恢复范围见[会话管理](conversations-and-agents.md#reset-and-delete-sessions)。

## 限制与故障 {#limits-and-failures}

模型失败、无效建议、并发修改、满额记忆或关闭会导致失败/部分完成；不自动回滚或重试。作用域分类依赖模型理解，服务端强制权限、工具与版本边界，但不能证明现实事实必然适用于所有话题。写入从后续轮次生效，不改已生成聊天。
