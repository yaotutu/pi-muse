# 对话与空间

本页说明手机客户端中的日常聊天、空间切换、消息反馈、停止运行、会话重置和空间删除。操作入口按当前移动端与服务端源码核对；源码不自动等于某个已发布 APK，实际界面以你安装的 Release 为准。

## 前提 {#prerequisites}

- 已按[快速上手](getting-started.md#connect-mobile-client)连接服务端，顶部连接状态为「已连接」。
- 已配置可用的外部模型；模型未配置时，聊天消息会被拒绝。
- 已区分「空间侧栏」和「会话面板」：左上角菜单打开的是空间侧栏；点击顶栏中间头像打开的是当前会话面板，可在面板中查看详细状态。

## 发送与停止对话 {#send-and-stop-conversations}

1. 在底部「聊天」页确认当前空间。若要换空间，先按「管理空间」操作。
2. 在「消息」输入框输入文字。需要随本条消息发送图片或文本时，点击[附件说明](files-and-approvals.md#send-attachments)中的「+」按钮。
3. 点击输入框右侧发送箭头。可见成功标志是你的消息进入聊天列表，右侧按钮变为停止方块；详细执行状态可在会话面板中查看。
4. 回复流式显示；模型调用工具时，消息中的工具卡或会话面板「动态」页会显示执行进展。
5. 需要停止时，点击同一个右侧按钮。运行中它显示为停止方块；等待状态同步时按钮不可用，先点「重新同步」。

停止成功后，本轮流状态会变为已停止或结束。同一前台连接内切换空间或主页面不会主动停止原空间生成，切回可查看进展；这不承诺后台持续运行。显式停止、断开聊天流、退出当前连接或服务重启仍会取消所属运行，未决文件审批也会作废；已经完成的工具操作不会回滚。

头像、空间菜单与空间入口悬浮在聊天内容上方，不单独占用一块固定顶栏。主空间不显示空间名称；其他空间仅在键盘收起时显示名称。聊天浮层不显示「就绪」「工作中」等状态文字，键盘展开时也不显示名称；详细状态仍在会话面板中，错误提示与面板内的待审批入口保留。发送新消息后视图会回到最新消息；主动上滚后可阅读旧内容，点击「回到最新」恢复跟随。

消息明确失败后可点击「恢复到输入框」。如果输入框已有新草稿，可取消处理、自行复制保存新草稿并清空输入框后再恢复旧消息，或点击「放弃未发送消息」并确认；放弃只删除这条未发送消息，保留当前草稿，且无法撤销。保存状态待确认时不能放弃或自动重发。

一个空间同一时间只允许一个聊天运行。发送状态未明或历史版本未同步时，客户端会锁住发送按钮；先点「重新同步」并核对权威历史，不要通过反复杀进程或重发绕过锁定。

## 消息反馈、评论与复制 {#message-feedback}

1. 在聊天页长按一条已保存的用户或助手消息气泡。正在生成的消息、发送中的本地消息和工具结果不支持反馈；已有喜欢、不喜欢或评论的消息也会在气泡边缘显示反馈徽标，点击徽标可重新打开。
2. 在弹出菜单的胶囊中点击「喜欢」或「不喜欢」。两者互斥；再次点击当前反应会撤销，点击另一项会切换。
3. 点击「评论」进入评论面板。输入 1–4000 字符后点击「发送」；服务端会去除首尾空白。
4. 对已有评论点击「编辑」，修改后保存；点击「删除」并确认后删除当前评论。一条消息可以有多条评论。
5. 点击「复制消息」把该条消息文本复制到系统剪贴板。复制只在本机执行；失败时页面会提示重试。

反馈作为服务端业务记录保存，属于当前空间、当前会话和这条消息；记录操作本身不会进入聊天历史、改变对话版本或触发偏好训练。服务端会保留反应变更以及评论新增、编辑和删除前的原始操作记录；删除评论只是让它不再显示。若当前空间显式开启信息后台，后台决策可读取本空间当前仍有效的反馈例证；回撤、编辑或删除后按最新投影读取。

如果反馈写入超时、断线或结果未明，界面会锁定后续修改并提示「刷新核对反馈」；先完整回读确认，再决定是否重新操作，客户端不会自动重试。重置当前会话会删除该空间的全部消息反馈；删除空间也会一并删除。

## 管理空间 {#manage-spaces}

1. 点击聊天页左上角菜单，打开空间侧栏。
2. 点击任意空间即切换；当前空间带选中标识，聊天页会随之切换历史、草稿和运行状态。
3. 在底部「搜索空间」框中输入显示名称或空间 ID 可过滤列表。
4. 点击右下角「新建空间」图标。客户端生成独立空间 ID 并立即切换；侧栏和键盘收起时的聊天页显示「空间 1」等易读名称，并在侧栏显示更新时间与真实运行状态。侧栏中的默认空间仍叫「主空间」。编号仅在当前连接内保持，不是服务端标题或跨设备名称。
5. 在新空间发送第一条消息，或进入「空间」保存空间规则/技能，使它在服务端真正建立。只点击「新建空间」而没有写操作时，它只是手机上的本地空条目，之后可能从服务端列表消失。

空间 ID 由字母开头，只含字母、数字、`_`、`-`，最长 64 字符。当前手机源码不提供服务端空间重命名或自动摘要入口；显示编号不改变空间 ID。

每个空间拥有独立会话历史、私有工作区、空间规则和技能开关。助手与用户资料、长期记忆、长期目标和技能资产是实例级全局内容，不随空间隔离；这不代表它们会全部进入每轮聊天。新空间是同一个人助手的新上下文，不是另一个独立助手。普通聊天会保留全局身份，并按当前空间实际启用的技能装配工具和对应说明；全局管理页面只是聚合展示，不改变这些数据的归属。详见[长期记忆与 Dream](memory-and-dream.md#memory-and-profile-boundaries)。

左侧抽屉底部只保留一个「设置」入口，统一管理新闻、短信、连接、浏览器、资料、记忆与本机主题；底部「空间」管理当前空间。头像面板只保留动态、审批和执行历史，「历史」不是其他聊天会话列表。空间二级页隐藏底部导航，系统返回逐层退回，空间首页再返回聊天。

## 空间规则与技能 {#space-rules-and-skills}

1. 进入底部「空间」，在全屏首页确认当前空间名称。
2. 点击「空间规则」或「空间技能」进入独立子页；规则可先阅读，再点击「编辑规则」编辑源码。
3. 在「空间规则」中填写你希望助手在本空间遵守的方式，点击「保存规则」。成功后读取值更新；规则从下一轮对话开始生效，不修改已生成历史。
4. 在「空间技能」中切换技能开关并点击「保存技能」。技能文件全局共用一份；开关只影响当前空间，并从下一轮对话开始改变实际可用工具和提示词中的对应使用说明。

空间规则最多 20,000 字符。返回时可保留当前连接内未保存草稿或明确丢弃；规则和技能分别保存、分别丢弃，不影响其他空间。换服务器或清理本机缓存会丢弃本地草稿。

## 功能与承接空间 {#query-information-background}

左上角空间侧栏只提供一个「设置」入口；进入设置页后，在「功能」分组管理新闻与短信。它们各有独立内部 Space，保存自己的原始内容、设置、处理记录与偏好，没有可切换的专属聊天窗口。默认交互承接空间是始终存在的「主空间」（`local-main`）；切换当前聊天空间不会改变绑定。

1. 打开「设置」，在「功能」分组选择「新闻」或「短信」。
2. 查看「交互承接空间」；需要更换时点击「更换承接空间」，选择已在服务器建立的普通空间。尚未保存任何内容的本地空空间不在候选中。
3. 更换只影响之后新接纳的后台轮次和新发起的讨论；已经接纳的在途轮次保留原目标。功能数据、偏好和历史消息不会迁移，旧消息仍关联原功能。绑定保存结果未明时，先「刷新核对」，不会自动重发。
4. 新闻阅读、RSS 与偏好见[新闻阅读](news.md)。短信在功能详情中管理，不能从当前空间设置中开启另一套短信。

### 短信处理 {#sms-processing}

1. 进入「设置」→「短信」，开启「启用短信处理」（首次默认关闭）。填写过滤指示并保存偏好，例如重要账单提醒、营销广告静默。
2. Android 独立原生构建中，点击授权短信权限。只有用户授予权限、应用进程存活且功能开启时，自动监听才可用；离开设置页或切换聊天空间不停止监听。应用被系统终止后不保证接收。Expo Go 不包含这个本地原生模块；可手动上报文本验证处理。
3. 新信息先进入短信功能的待处理队列，由真实模型批量判断。静默不产生聊天消息；需要提醒的结果进入绑定空间的会话，显示「来自短信」。不是操作系统推送通知；打开的聊天通过现有通知连接重读权威历史。
4. 可在承接会话中针对提醒明确说“不喜欢这条短信，少提醒这种内容”。助手使用受限 `feature` 工具沿服务端消息来源读取原始内容，将反应或评论保存回短信功能。反馈不写全局记忆或普通空间规则，也不把一次不喜欢变成永久屏蔽。

对带来源消息的气泡点赞/不喜欢和评论，功能下一轮会按消息关联读取当前有效例证；撤销、编辑或删除按最新结果读取。绑定更换不改写旧消息来源。重置聊天删除该聊天的气泡反馈与关联，不删除功能本身的原文、逐条反馈或偏好，也不恢复被清除的消息。

既有普通空间的通用信息后台数据与 API 保留，不自动迁移、删除或接管为短信功能。已开启的旧后台仍按原空间处理；其只读 `information` 工具只查询本空间。独立功能使用专用入口和受限来源工具，不因此开放任意跨空间文件访问。

## 重置与删除空间 {#reset-and-delete-spaces}

### 重置当前会话 {#reset-current-session}

1. 进入底部「空间」→「空间维护」→「重置当前会话」。
2. 核对对话框中的目标空间。
3. 默认重置会停止当前运行，清空该空间聊天历史、消息反馈、未完成审批、Dream 整理游标、最近整理结果与待决建议，并开启全新会话；空间规则、技能开关、Dream 配置、私有工作区文件、信息后台设置、原始信息、执行记录和偏好备注会保留。
4. 如需同时删除该空间绑定的定时任务与网页监控，勾选「同时清理此空间下的定时任务与网页监控」。默认不勾选，任务和监控会转绑到新会话。
5. 点击「确认重置」。成功后显示「会话已重置」，可开启全新对话。

被清空的聊天历史和消息反馈无法恢复。重置会取消尚未落盘的信息通知；历史发布关系仍可追溯，但旧会话反馈不会迁移为新的偏好例证。若网络结果未明，客户端会显示待确认并暂停发送；先点击「核对重置结果」，不要自动重试重置。

### 删除空间 {#delete-space}

1. 在空间侧栏切到要删除的非主空间。
2. 进入底部「空间」→「空间维护」。
3. 滚动到「删除当前空间」，点击进入确认卡片。
4. 核对删除范围后点击「确认删除」。

::: danger 不可恢复删除
删除空间会彻底清除该空间的聊天历史、消息反馈、私有工作区文件、空间规则、技能配置、Dream 配置与整理状态、信息后台数据，以及绑定的定时任务和网页监控。操作不可撤销，不会自动迁移到主空间。主空间不可删除；绑定功能的其他空间须先在「设置」中显式更换承接空间，否则删除会被拒绝，不会自动回退主空间。只想清空对话时使用「重置当前会话」。
:::

删除请求结果未明时，先刷新空间列表核对，不要重发删除请求。删除成功后，之后使用相同 ID 新建空间也不会恢复旧历史。
