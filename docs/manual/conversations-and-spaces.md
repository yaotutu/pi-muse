# 对话与空间

本页说明手机客户端中的默认群聊、成员私聊、成员主页、消息反馈、停止运行、会话重置和空间删除。操作入口按当前移动端与服务端源码核对；源码不自动等于某个已发布 APK，实际界面以你安装的 Release 为准。

## 前提 {#prerequisites}

- 已按[快速上手](getting-started.md#connect-mobile-client)连接服务端，顶部连接状态为「已连接」。
- 已配置可用的外部模型；模型未配置时，聊天消息会被拒绝。
- 冷启动直接进入「群聊」，没有底部导航。左上角返回「会话」列表，群聊右上角打开「群组信息」和成员列表；私聊右上角齿轮打开当前「空间设置」。全局设置只在会话列表顶部。新闻阅读入口仍在新闻成员主页。

## 默认群聊与定向消息 {#group-chat}

群聊不是另一个 Space，把群内消息与来源已验证的功能通知按真实发送成员的头像放在同一时间线上。每个成员在群里的上下文与自己的私聊独立；不会把整个群历史交给任何模型。

1. 不选择成员、也不输入 `@` 时，消息只交给 Muse（main，`local-main`），其他成员不收到，也不自动回复。
2. 点击输入框左侧 `@` 选择成员，或在开头输入 `@显示名称 `／`@Space-ID `，本条消息只交给该成员。发送完成并回读确认后清除目标，下一条恢复默认 main。未知成员会报错，不退回 main；每条消息只支持一个目标。
3. 成员可通过真实的 `space` 工具显式请另一成员处理任务；时间线显示发起者、目标与回复者，只有传入的请求与必要上下文被交给目标，不广播其他消息。
4. 点消息头像或「群组信息」中的成员进入主页，再点「发消息」进入独立私聊；私聊右上角是该成员的空间设置。群组信息返回群聊，主页返回实际进入它的页面。
5. 发送箭头在运行中变为停止方块。网络结果未明时先点「同步核对」，不自动重发；断流、退出连接或服务重启会取消所属执行，已完成的操作不回滚。群聊文件修改仍需查看完整差异并审批，待审批时从「待处理审批」进入。

当前群聊只支持文本与工具结果展示，不支持附件、消息反馈、通知卡片定向续聊或多个群组。附件与消息反馈请进入成员私聊。短信后台提醒及新闻「带到会话讨论」仍只落盘到实际承接空间的私聊；默认群聊只读展示这些带服务端来源标记的通知，不合并普通私聊。通知显示来源成员与「由谁承接 · 查看私聊」，点击后进入该条通知的实际承接私聊继续处理。改绑不移动旧通知；承接会话重置或删除后，群里不再显示已清除的通知。查看通知不触发模型、不改变群聊输入目标；普通群聊回复仍按默认 main 或显式 `@` 处理，不会自动关联这条通知。

群聊顶栏不会遮住消息。成员头像在回复左侧，名称、正文与工具结果保持在同一列；定向的 `@成员` 与正文开头同行显示，不加底色，在蓝色气泡中以白色中等字重显示，在成员气泡中使用主题强调色，长文本自然换行；代码块、表格等仍保留块级排版。同一条回复的工具结果默认合为一条「工具记录」，显示数量及真实结果状态；失败数与尚无结果数不会被隐藏。点击该行展开各项摘要和来源，再点一次收起。停止或失败提示留在对应回复下方，不堆在历史末尾。

## 发送与停止对话 {#send-and-stop-conversations}

以下步骤针对成员私聊；群聊见[默认群聊](#group-chat)。

1. 从「会话」列表点击成员消息行进入私聊，或点击头像进入主页后点「发消息」。
2. 在「消息」输入框输入文字。需要随本条消息发送图片或文本时，点击[附件说明](files-and-approvals.md#send-attachments)中的「+」按钮。
3. 点击输入框右侧发送箭头。可见成功标志是你的消息进入聊天列表，右侧按钮变为停止方块；详细执行状态可在会话面板中查看。
4. 回复流式显示；模型调用工具时，消息中的工具卡或会话面板「动态」页会显示执行进展。
5. 需要停止时，点击同一个右侧按钮。运行中它显示为停止方块；等待状态同步时按钮不可用，先点「重新同步」。

停止成功后，本轮流状态会变为已停止或结束。同一前台连接内切换空间或主页面不会主动停止原空间生成，切回可查看进展；这不承诺后台持续运行。显式停止、断开聊天流、退出当前连接或服务重启仍会取消所属运行，未决文件审批也会作废；已经完成的工具操作不会回滚。

头像、返回消息列表与动态按钮悬浮在聊天内容上方，不单独占用一块固定顶栏。主空间不显示空间名称；其他空间仅在键盘收起时显示名称。聊天浮层不显示「就绪」「工作中」等状态文字，键盘展开时也不显示名称；详细状态仍在会话面板中，错误提示与面板内的待审批入口保留。发送新消息后视图会回到最新消息；主动上滚后可阅读旧内容，点击「回到最新」恢复跟随。

消息明确失败后可点击「恢复到输入框」。如果输入框已有新草稿，可取消处理、自行复制保存新草稿并清空输入框后再恢复旧消息，或点击「放弃未发送消息」并确认；放弃只删除这条未发送消息，保留当前草稿，且无法撤销。保存状态待确认时不能放弃或自动重发。

一个空间同一时间只允许一个聊天运行。发送状态未明或历史版本未同步时，客户端会锁住发送按钮；先点「重新同步」并核对权威历史，不要通过反复杀进程或重发绕过锁定。

## 消息反馈、评论与复制 {#message-feedback}

1. 在聊天页长按一条已保存的用户或助手消息气泡。正在生成的消息、发送中的本地消息和工具结果不支持反馈；已有喜欢、不喜欢或评论的消息也会在气泡边缘显示反馈徽标，点击徽标可重新打开。
2. 在弹出菜单的胶囊中点击「喜欢」或「不喜欢」。两者互斥；再次点击当前反应会撤销，点击另一项会切换。
3. 点击「评论」进入评论面板。输入 1–4000 字符后点击「发送」；服务端会去除首尾空白。
4. 对已有评论点击「编辑」，修改后保存；点击「删除」并确认后删除当前评论。一条消息可以有多条评论。
5. 点击「复制消息」把该条消息文本复制到系统剪贴板。复制只在本机执行；失败时页面会提示重试。

反馈作为服务端业务记录保存，属于当前空间、当前会话和这条消息；记录操作本身不会进入聊天历史、改变对话版本或触发偏好训练。服务端会保留反应变更以及评论新增、编辑和删除前的原始操作记录；删除评论只是让它不再显示。若当前空间显式开启信息后台，后台决策可读取本空间当前仍有效的反馈例证；回撤、编辑或删除后按最新投影读取。

如果反馈写入超时、断线或结果未明，界面会锁定后续修改并提示「刷新核对反馈」；先完整回读确认，再决定是否重新操作，客户端不会自动重试。重置当前会话会删除该空间的全部消息反馈；删除空间也会一并删除。

## 管理空间 {#manage-spaces}

1. 「会话」是唯一列表：顶部群聊行和右下角「回到群聊」打开默认群聊；成员消息行进入私聊，头像进入主页。聊天左上角回到列表，不打开侧栏。
2. 主页提供「发消息」、文件、专属规则、技能、会话管理及动态与审批。新闻和短信另有各自的功能设置；全局设置位于会话列表右上角齿轮。主页返回进入它的群聊、群组信息、私聊或列表；空间设置从聊天进入时返回原私聊；新闻阅读器返回新闻成员主页。切回前台保留原页面，不强制跳回 Muse。
3. 顶部搜索按成员显示名称或 Space ID 本地筛选。点击加号后先由服务端创建普通成员，成功后进入主页；尚未聊天也会保留，重启客户端或服务后仍能找到，并可立即在群聊中 `@` 或选择为通知承接方。创建期间不能重复点击；失败留在列表提示，响应未明时先按原 ID 回读核对，不生成第二个成员自动重试。
4. 默认成员显示为 Muse、新闻、短信；其他成员显示「成员 1」等连接内编号，不提供持久化改名或自定义头像。

每个成员仍对应原来的 Space，独立保存私聊历史、私有工作区、规则与技能开关。Space ID、文件和现有历史不迁移。助手与用户资料、长期记忆和技能资产仍是实例级全局内容；成员称谓不等于新增独立账号或自动产生不同人设。

新闻和短信可独立私聊；打开主页或发送私聊不会自动开启后台处理、申请短信权限或改变通知承接空间。后台通知仍默认送往 main，可在功能设置显式改绑到已存在的普通空间。各自私聊和跨空间讨论互不拼接历史。

会话列表的群聊行显示最新消息或功能通知的来源、摘要与本地时间，通过同一条通知连接更新；同步失败保留旧摘要并提示核对。普通成员行暂不展示最后消息、未读数或最近排序；群聊内通过显式 `@` 定向，通知可进入承接私聊，但尚不支持在群内直接定向续聊。

## 空间规则与技能 {#space-rules-and-skills}

1. 点击成员头像进入主页，确认成员名称。
2. 点击「专属规则」或「技能」进入独立子页；规则可先阅读，再点击「编辑规则」编辑源码。
3. 在「空间规则」中填写你希望助手在本空间遵守的方式，点击「保存规则」。成功后读取值更新；规则从下一轮对话开始生效，不修改已生成历史。
4. 在「空间技能」中切换技能开关并点击「保存技能」。技能文件全局共用一份；开关只影响当前空间，并从下一轮对话开始改变实际可用工具和提示词中的对应使用说明。

空间规则最多 20,000 字符。返回时可保留当前连接内未保存草稿或明确丢弃；规则和技能分别保存、分别丢弃，不影响其他空间。换服务器或清理本机缓存会丢弃本地草稿。

## 功能与承接空间 {#query-information-background}

新闻与短信从各自成员主页进入功能设置。它们各有独立 Space，保存原始内容、处理记录、偏好与私聊历史；后台通知默认承接方仍是 main（`local-main`），选择私聊成员不会改变绑定。

1. 打开新闻或短信的成员主页，进入「新闻设置」或「短信设置」。
2. 查看「交互承接空间」；需要更换时点击「更换承接空间」，选择已在服务器建立的普通空间。尚未保存任何内容的本地空空间不在候选中。
3. 更换只影响之后新接纳的后台轮次和新发起的讨论；已经接纳的在途轮次保留原目标。功能数据、偏好和历史消息不会迁移，旧消息仍关联原功能。绑定保存结果未明时，先「刷新核对」，不会自动重发。
4. 新闻阅读、RSS 与偏好见[新闻阅读](news.md)。短信在功能详情中管理，不能从当前空间设置中开启另一套短信。

### 让其他空间处理任务 {#space-communication}

可以在当前聊天中明确要求「交给短信功能查一下快递短信」或「让另一个空间处理这件事」。助手可发现已有空间，将请求交给目标空间的独立讨论处理，再把结果带回当前聊天；main 不是唯一入口，功能空间也可以向其他空间请求帮助。项目内部默认互信，不需要先改通知绑定或逐次授权空间调用。

目标使用自己的规则、技能、工作区与已有信息，不自动复制任何一边的主聊天历史。追问同一件事时，助手可延续同一个讨论；如果对方需要补充信息，先回答问题再继续，不会一直占着模型等待用户。短信后台处理关闭不妨碍查询已经接纳的数据，但不会因此自动读取手机历史收件箱。

请求结果回复发起方，后台主动通知才使用设置中的承接空间。停止当前运行会取消关联请求；失败不自动重试，已完成的副作用不会回滚。重置目标空间会清除该空间的独立讨论；重置来源不会删除另一个空间的讨论，也不会把旧回复投递到新会话。

群聊提供显式 `@` 与输入目标提示；私聊普通输入仍先由当前成员理解。通知卡片「继续处理」与独立讨论页面尚未提供，评论反馈不是执行任务。

### 短信处理 {#sms-processing}

1. 进入短信成员主页的「短信设置」，开启「启用短信处理」（首次默认关闭）。填写过滤指示并保存偏好，例如重要账单提醒、营销广告静默。
2. Android 独立原生构建中，点击授权短信权限。只有用户授予权限、应用进程存活且功能开启时，自动监听才可用；离开设置页或切换聊天空间不停止监听。应用被系统终止后不保证接收。Expo Go 不包含这个本地原生模块；可手动上报文本验证处理。
3. 新信息先进入短信功能的待处理队列，由真实模型批量判断。静默不产生聊天消息；需要提醒的结果进入绑定空间的会话，显示「来自短信」。不是操作系统推送通知；默认群聊、会话列表群聊摘要和承接私聊通过同一条通知连接重读权威状态，重连后同样核对。
4. 短信设置页打开且应用在前台时，每 5 秒只读核对开关、偏好和最近 10 条信息；后台静默分析也会更新「待分析／分析中／已分析／分析失败」状态。离开页面或进入后台停止定时刷新，重新打开或回到前台会核对状态。自动刷新与「刷新核对」都保留未保存的过滤指示；读取失败保留上次记录，不显示为空列表。写入或分析结果未明时，仍需手动「刷新核对」，不会自动重发或重跑。
5. 可在承接会话中针对提醒明确说“不喜欢这条短信，少提醒这种内容”。助手使用受限 `feature` 工具沿服务端消息来源读取原始内容，将反应或评论保存回短信功能。反馈不写全局记忆或普通空间规则，也不把一次不喜欢变成永久屏蔽。

对带来源消息的气泡点赞/不喜欢和评论，功能下一轮会按消息关联读取当前有效例证；撤销、编辑或删除按最新结果读取。绑定更换不改写旧消息来源。重置聊天删除该聊天的气泡反馈与关联，不删除功能本身的原文、逐条反馈或偏好，也不恢复被清除的消息。

既有普通空间的通用信息后台数据与 API 保留，不自动迁移、删除或接管为短信功能。已开启的旧后台仍按原空间处理；其只读 `information` 工具只查询本空间。独立功能使用专用入口和受限来源工具，不因此开放任意跨空间文件访问。

## 重置与删除空间 {#reset-and-delete-spaces}

### 重置当前会话 {#reset-current-session}

1. 进入成员主页→「会话管理」→「重置当前会话」。
2. 核对对话框中的目标空间。
3. 默认重置会停止当前运行，清空该空间私聊历史、该成员的群聊讨论和显示记录、消息反馈、未完成审批、Dream 整理游标、最近整理结果与待决建议，并开启全新会话；空间规则、技能开关、Dream 配置、私有工作区文件、信息后台设置、原始信息、执行记录和偏好备注会保留。
4. 如需同时删除该空间绑定的定时任务与网页监控，勾选「同时清理此空间下的定时任务与网页监控」。默认不勾选，任务和监控会转绑到新会话。
5. 点击「确认重置」。成功后显示「会话已重置」，可开启全新对话。

被清空的聊天历史和消息反馈无法恢复。重置会取消尚未落盘的信息通知；历史发布关系仍可追溯，但旧会话反馈不会迁移为新的偏好例证。若网络结果未明，客户端会显示待确认并暂停发送；先点击「核对重置结果」，不要自动重试重置。

### 删除空间 {#delete-space}

1. 打开要删除的普通成员主页。
2. 进入成员主页→「会话管理」。
3. 滚动到「删除当前空间」，点击进入确认卡片。
4. 核对删除范围后点击「确认删除」。

::: danger 不可恢复删除
删除空间会彻底清除该空间的私聊历史、群聊讨论与显示记录、消息反馈、私有工作区文件、空间规则、技能配置、Dream 配置与整理状态、信息后台数据，以及绑定的定时任务和网页监控。操作不可撤销，不会自动迁移到主空间。Muse、新闻和短信内置成员不可删除；绑定功能的其他空间须先在对应功能成员的设置中显式更换承接空间，否则删除会被拒绝，不会自动回退主空间。只想清空对话时使用「重置当前会话」。
:::

删除请求结果未明时，先刷新空间列表核对，不要重发删除请求。删除成功后，之后使用相同 ID 新建空间也不会恢复旧历史。
