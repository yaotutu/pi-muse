# 对话与会话

Pi Muse 只有一个助手身份。移动端当前只聚焦默认主聊天：点击底部「消息」就能直接聊天，不需要选择或创建会话。本文对应当前源码；已安装版本的入口需核对对应发布版本。

## 前提 {#prerequisites}

按[快速上手](getting-started.md#connect-mobile-client)连接匹配版本的服务端。聊天需要已配置可用外部模型。

## 主聊天 {#session-model}

「消息」直接使用永久默认会话 `main`，显示消息和输入框，不再先显示会话列表。切到新闻或设置不会清空草稿，也不会仅因隐藏聊天而中断正在运行的流。

主聊天不可删除，但可以重置。身份资料、长期记忆和工作区仍是实例全局内容；长期记忆按需检索，不每轮全量加载。

助手形象直接悬浮在聊天内容区顶部中央，无底座，仅有一圈很淡的轮廓帮助与内容分离，也不再单独占用一整行页头。状态由形象的姿态表达，精确状态保留在形象的读屏标签里。内容不满一屏时，第一条消息从形象下方开始，不与形象重叠；内容滚满一屏后，顶部起排空间随之滚出视口，阅读位置不保留可见空白，滚动中的内容仍从形象后方经过。形象两侧仍可滑动聊天。点击形象打开主聊天操作，查看执行、审批和历史，或进入重置、指令与技能设置。形象只在消息页显示，切换新闻或设置不会重建聊天。

## 发送与停止对话 {#send-and-stop-conversations}

直接在「消息」输入文字，或按[附件说明](files-and-approvals.md#send-attachments)随该条消息提交图片/文本。模型回复以流式显示，工具与审批呈现实际执行事实。

同一时间只有一个主聊天运行。停止绑定本次运行，不影响后续轮次。断开聊天流、显式停止、超时或服务关闭会取消所属运行及子调用，未决审批作废；已有副作用不回滚。通知连接断开不等于停止聊天。

发送或写操作结果未明时，先同步权威历史/状态，不自动重发。切换页面不自动重发消息，不承诺应用进程终止后的继续执行。

## 消息反馈 {#message-feedback}

已保存的用户/助手消息可喜欢、不喜欢、撤销反应以及增删改评论；正在生成的消息和工具结果不可反馈。喜欢/不喜欢互斥，评论去首尾空白后 1–4000 字符。

反馈绑定公开会话、内部 pi 会话与消息 id，独立保存原始操作事件，不改变聊天版本、不触发模型或训练。重置后旧内部身份不能继续写反馈。写入超时或结果未明先回读确认，不自动重试。

## 主聊天规则与技能 {#session-rules-and-skills}

从聊天操作或设置中的指令、技能入口修改主聊天配置。规则保存到 main 的 INSTRUCTIONS.md，下一轮重读，最多 20,000 字符；空串是明确清空。最后成功保存生效，不自动合并。规则不能增加工具、扩大路径或绕过审批。

技能文本是全局资产，启用覆盖在主聊天下一轮生效。main 的规则同时是短信过滤与新闻偏好的入口，保存时应核对完整内容。

## 新闻与短信 {#background-services}

新闻是后台 RSS 与推荐管线，阅读见[新闻](news.md)。文章「讨论」直接将标记为不可信的引用追加到主聊天既有草稿，可编辑，不自动发送，也不弹出会话选择器；可返回原文章继续阅读。

短信是实例全局管线，首次默认关闭。后台分析重要短信后，系统通知直接写入主聊天历史，不额外启动一次主聊天模型回复。静默或失败不会制造通知。

短信采集依赖 Android 原生模块、系统权限、功能启用与应用进程存活；不承诺进程终止后采集或操作系统推送。导入/执行结果未明先核对条目和处理记录，不自动重发或重跑。

## 子代理 {#subagent}

助手可调用 `subagent` 完成一次受限的 single/parallel/chain 工作。它只有内存上下文、不创建会话或目录，使用相同工作区，结果返回父工具调用。它不能递归委派、排程、监控、登记独立活动或修改会话指令；角色只收窄权限。文件修改仍逐次人工审批，父停止会取消子执行。

## 重置主聊天 {#reset-and-delete-sessions}

### 确认重置范围 {#reset-current-session}

确认不可恢复范围后再提交。重置停止当前运行、取消待审批，清空聊天 JSONL 和消息反馈并换新内部 pi 身份。公开 id、规则、技能覆盖和工作区保留。可选同时清理任务与监控，缺省保留。

重置不删除新闻、短信、全局记忆或全局 Dream 配置。结果未明先回读历史和状态，不自动重复重置。

### 专题入口暂缓 {#delete-session}

移动端暂不提供专题会话的新建、选择、切换、改名或删除入口。服务端多会话底座仍保留；收起客户端入口不会删除既有专题数据，也不改变 main 不可删除的约束。
