# 对话与智能体

本页说明手机客户端中的默认「全部」视图、智能体私聊与设置、消息反馈、停止运行、会话重置和智能体删除。操作入口按当前移动端与服务端源码核对；源码不自动等于某个已发布 APK，实际界面以你安装的 Release 为准。

## 前提 {#prerequisites}

- 已按[快速上手](getting-started.md#connect-mobile-client)连接服务端；可在「设置」→「服务器连接」核对连接状态。
- 已配置可用的外部模型；模型未配置时，聊天消息会被拒绝。
- 冷启动直接进入「全部」，没有底部导航或独立会话列表。单击顶部头像切换「全部」或智能体私聊，单击已选头像不做额外操作。长按「全部」打开「全局设置」，长按智能体头像打开其「智能体设置」；聊天右上角不再放按钮。添加、删除集中在全局设置的「智能体管理」。

## 智能体、会话与扩展 {#agent-model}

「智能体」是独立的执行主体，不只是会话名称。每个智能体有自己的私聊上下文与在「全部」中的讨论上下文、消息历史、专属指令、技能开关和私有文件；重置会话改变 sessionId，不改变稳定 agentId 或专属配置。

新闻和短信也是完整智能体。新闻阅读、RSS 管理和短信后台处理是附加能力与视图，不是另一种受限成员类型。它们同样可以私聊、使用自己的指令和技能、参与 Dream、拥有任务和承接通知；打开聊天不会自动启用采集或申请短信权限。

实例模型、SOUL/USER、身份资料、长期记忆与技能资产仍共享。记忆按现有工具和检索机制按需使用，不会因为改名就自动复制或注入所有记忆。成员间只通过显式请求传递必要内容，聚合展示不等于共享模型上下文。

当前 Agent 版本不提供旧 Space/Thread 接口或自动数据迁移。旧实例需停服备份并另行确认转换，不能只改私有文件目录就直接启动。

## 「全部」视图与定向消息 {#group-chat}

「全部」是聚合展示，不是向所有智能体广播，也不是另一个 Agent；它把讨论消息与来源已验证的功能通知按真实发送成员的头像放在同一时间线上。每个成员在此视图中的讨论上下文与自己的私聊独立；不会把整条时间线交给任何模型。

1. 不选择成员、也不输入 `@` 时，消息只交给 Muse（main，`local-main`），其他成员不收到，也不自动回复。
2. 点击输入框左侧 `@` 选择成员，或在开头输入 `@显示名称 `／`@Agent-ID `，本条消息只交给该成员。发送完成并回读确认后清除目标，下一条恢复默认 main。未知成员会报错，不退回 main；每条消息只支持一个目标。
3. 成员可通过真实的 `agent` 工具显式请另一成员处理任务；时间线显示发起者、目标与回复者，只有传入的请求与必要上下文被交给目标，不广播其他消息。
4. 单击顶部智能体头像进入独立私聊；点消息中的成员头像直接打开该智能体设置。设置页返回实际进入它的聊天，不改变原聊天对象。
5. 发送箭头在运行中变为停止方块。网络结果未明时先点「同步核对」，不自动重发；断流、退出连接或服务重启会取消所属执行，已完成的操作不回滚。在「全部」中请求的文件修改仍需查看完整差异并审批，待审批时从「待处理审批」进入。

当前「全部」只支持文本与工具结果展示，不支持附件、消息反馈、通知卡片定向续聊或多个群组。附件与消息反馈请进入成员私聊。短信后台提醒及新闻「带到会话讨论」仍只落盘到实际承接智能体的私聊；「全部」只读展示这些带服务端来源标记的通知，不合并普通私聊。通知显示来源成员与「由谁承接 · 查看私聊」，点击后进入该条通知的实际承接私聊继续处理。改绑不移动旧通知；承接会话重置或删除后，「全部」中不再显示已清除的通知。查看通知不触发模型、不改变「全部」输入目标；「全部」中的普通回复仍按默认 main 或显式 `@` 处理，不会自动关联这条通知。

「全部」顶栏不会遮住消息。成员头像在回复左侧，名称、正文与工具结果保持在同一列；定向的 `@成员` 与正文开头同行显示，不加底色，在蓝色气泡中以白色中等字重显示，在成员气泡中使用主题强调色，长文本自然换行；代码块、表格等仍保留块级排版。同一条回复的工具结果默认合为一条「工具记录」，显示数量及真实结果状态；失败数与尚无结果数不会被隐藏。点击该行展开各项摘要和来源，再点一次收起。停止或失败提示留在对应回复下方，不堆在历史末尾。

## 发送与停止对话 {#send-and-stop-conversations}

以下步骤针对成员私聊；聚合聊天见[「全部」视图](#group-chat)。

1. 单击顶部智能体头像进入私聊。左右快速滑动消息阅读区可切换相邻聊天，到两端不循环；输入区与设置子页不参与切换。
2. 在「消息」输入框输入文字。需要随本条消息发送图片或文本时，点击[附件说明](files-and-approvals.md#send-attachments)中的「+」按钮。
3. 点击输入框右侧发送箭头。可见成功标志是你的消息进入聊天列表，右侧按钮变为停止方块；详细执行状态可在会话面板中查看。
4. 回复流式显示；模型调用工具时，消息中的工具卡或会话面板「动态」页会显示执行进展。
5. 需要停止时，点击同一个右侧按钮。运行中它显示为停止方块；等待状态同步时按钮不可用，先点「重新同步」。

停止成功后，本轮流状态会变为已停止或结束。同一前台连接内切换智能体或主页面不会主动停止原智能体生成，切回可查看进展；这不承诺后台持续运行。显式停止、断开聊天流、退出当前连接或服务重启仍会取消所属运行，未决文件审批也会作废；已经完成的工具操作不会回滚。

顶部头像栏占正常布局高度，不遮挡消息。「全部」固定在最前，随后为 Muse、新闻、短信与其他智能体，顺序不随聊天活跃时间跳动。阅读消息时快速左右滑动切换相邻聊天，边界不循环；纵向阅读、输入框、二级页面以及代码和表格横向滚动不参与切换。键盘展开时隐藏头像名称以让出阅读空间；详细状态仍在动态与审批面板中。切换保留当前连接内的各自草稿与正在生成的回复。发送新消息后回到最新；主动上滚后点击「回到最新」恢复跟随。

消息明确失败后可点击「恢复到输入框」。如果输入框已有新草稿，可取消处理、自行复制保存新草稿并清空输入框后再恢复旧消息，或点击「放弃未发送消息」并确认；放弃只删除这条未发送消息，保留当前草稿，且无法撤销。保存状态待确认时不能放弃或自动重发。

一个智能体同一时间只允许一个聊天运行。发送状态未明或历史版本未同步时，客户端会锁住发送按钮；先点「重新同步」并核对权威历史，不要通过反复杀进程或重发绕过锁定。

## 消息反馈、评论与复制 {#message-feedback}

1. 在聊天页长按一条已保存的用户或助手消息气泡。正在生成的消息、发送中的本地消息和工具结果不支持反馈；已有喜欢、不喜欢或评论的消息也会在气泡边缘显示反馈徽标，点击徽标可重新打开。
2. 在弹出菜单的胶囊中点击「喜欢」或「不喜欢」。两者互斥；再次点击当前反应会撤销，点击另一项会切换。
3. 点击「评论」进入评论面板。输入 1–4000 字符后点击「发送」；服务端会去除首尾空白。
4. 对已有评论点击「编辑」，修改后保存；点击「删除」并确认后删除当前评论。一条消息可以有多条评论。
5. 点击「复制消息」把该条消息文本复制到系统剪贴板。复制只在本机执行；失败时页面会提示重试。

反馈作为服务端业务记录保存，属于当前智能体、当前会话和这条消息；记录操作本身不会进入聊天历史、改变对话版本或触发偏好训练。服务端会保留反应变更以及评论新增、编辑和删除前的原始操作记录；删除评论只是让它不再显示。若当前智能体显式开启信息后台，后台决策可读取本智能体当前仍有效的反馈例证；回撤、编辑或删除后按最新投影读取。

如果反馈写入超时、断线或结果未明，界面会锁定后续修改并提示「刷新核对反馈」；先完整回读确认，再决定是否重新操作，客户端不会自动重试。重置当前会话会删除该智能体的全部消息反馈；删除智能体也会一并删除。

## 管理智能体 {#manage-agents}

1. 单击顶部头像切换聊天，长按「全部」进入全局设置，长按某智能体进入其设置。已选头像单击无额外动作。私聊按 Android 返回键回「全部」；键盘和覆盖面板先关闭。
2. 智能体设置提供文件、专属规则、技能、会话管理及动态与审批；新闻另有「阅读新闻」，新闻和短信各有功能设置。查看另一个智能体设置不会切换原聊天、清除草稿或停止生成；返回原来的「全部」或私聊。从智能体管理进入设置则返回管理页，新闻阅读器先返回新闻设置。
3. 长按「全部」→「智能体管理」→「添加智能体」。先由服务端确认创建，成功后进入新智能体设置，但不切换原聊天。尚未聊天也可在重启后找到，并用于 `@` 或通知承接。创建期间禁止重复点击和返回；失败留在管理页，结果未明先按原 ID 回读，不自动创建第二个智能体。
4. 默认成员显示为 Muse、新闻、短信；其他成员显示「成员 1」等连接内编号，不提供持久化改名或自定义头像。

每个成员仍对应原来的 Agent，独立保存私聊历史、私有工作区、规则与技能开关。稳定 Agent ID 不随会话重置改变。助手与用户资料、长期记忆和技能资产仍是实例级全局内容；成员称谓不等于新增独立账号或自动产生不同人设。

从智能体设置打开「动态与审批」时，面板覆盖原页面并默认显示「动态」。关闭或按 Android 返回后仍在原设置页，返回来源不变；键盘打开时先收起键盘。

新闻和短信可独立私聊。查看设置或发送私聊不会自动开启后台处理、申请短信权限或改变通知承接智能体。后台通知仍默认送往 main，可在功能设置显式改绑到任意已存在智能体。各自私聊和跨智能体讨论互不拼接历史。

## 智能体规则与技能 {#agent-rules-and-skills}

1. 长按顶部智能体头像进入其设置，确认智能体名称。
2. 点击「专属规则」或「技能」进入独立子页；规则可先阅读，再点击「编辑规则」编辑源码。
3. 在「智能体规则」中填写你希望助手在本智能体遵守的方式，点击「保存规则」。成功后读取值更新；规则从下一轮对话开始生效，不修改已生成历史。
4. 在「智能体技能」中切换技能开关并点击「保存技能」。技能文件全局共用一份；开关只影响当前智能体，并从下一轮对话开始改变实际可用工具和提示词中的对应使用说明。

智能体规则最多 20,000 字符。返回时可保留当前连接内未保存草稿或明确丢弃；规则和技能分别保存、分别丢弃，不影响其他智能体。换服务器或清理本机缓存会丢弃本地草稿。

## 功能与承接智能体 {#query-information-background}

新闻与短信从各自智能体设置进入功能设置。它们各有独立 Agent，保存原始内容、处理记录、偏好与私聊历史；后台通知默认承接方仍是 main（`local-main`），选择私聊成员不会改变绑定。

1. 长按新闻或短信头像打开其智能体设置，进入「新闻设置」或「短信设置」。
2. 查看「交互承接智能体」；需要更换时点击「更换承接智能体」，选择已在服务器建立的任意智能体。尚未保存任何内容的本地空智能体不在候选中。
3. 更换只影响之后新接纳的后台轮次和新发起的讨论；已经接纳的在途轮次保留原目标。功能数据、偏好和历史消息不会迁移，旧消息仍关联原功能。绑定保存结果未明时，先「刷新核对」，不会自动重发。
4. 新闻阅读、RSS 与偏好见[新闻阅读](news.md)。短信在功能详情中管理，不能从当前智能体设置中开启另一套短信。

### 让其他智能体处理任务 {#agent-communication}

可以在当前聊天中明确要求「交给短信功能查一下快递短信」或「让另一个智能体处理这件事」。助手可发现已有智能体，将请求交给目标智能体的独立讨论处理，再把结果带回当前聊天；main 不是唯一入口，新闻和短信智能体也可以向其他智能体请求帮助。项目内部默认互信，不需要先改通知绑定或逐次授权智能体调用。

目标使用自己的规则、技能、工作区与已有信息，不自动复制任何一边的主聊天历史。追问同一件事时，助手可延续同一个讨论；如果对方需要补充信息，先回答问题再继续，不会一直占着模型等待用户。短信后台处理关闭不妨碍查询已经接纳的数据，但不会因此自动读取手机历史收件箱。

请求结果回复发起方，后台主动通知才使用设置中的承接智能体。停止当前运行会取消关联请求；失败不自动重试，已完成的副作用不会回滚。重置目标智能体会清除该智能体的独立讨论；重置来源不会删除另一个智能体的讨论，也不会把旧回复投递到新会话。

「全部」提供显式 `@` 与输入目标提示；私聊普通输入仍先由当前成员理解。通知卡片「继续处理」与独立讨论页面尚未提供，评论反馈不是执行任务。

### 短信处理 {#sms-processing}

1. 长按短信头像→「短信设置」，开启「启用短信处理」（首次默认关闭）。填写过滤指示并保存偏好，例如重要账单提醒、营销广告静默。
2. Android 独立原生构建中，点击授权短信权限。只有用户授予权限、应用进程存活且功能开启时，自动监听才可用；离开设置页或切换聊天智能体不停止监听。应用被系统终止后不保证接收。Expo Go 不包含这个本地原生模块；可手动上报文本验证处理。
3. 新信息先进入短信功能的待处理队列，由真实模型批量判断。静默不产生聊天消息；需要提醒的结果进入绑定智能体的会话，显示「来自短信」。不是操作系统推送通知；「全部」和承接私聊通过同一条通知连接重读权威状态，重连后同样核对。
4. 短信设置页打开且应用在前台时，每 5 秒只读核对开关、偏好和最近 10 条信息；后台静默分析也会更新「待分析／分析中／已分析／分析失败」状态。离开页面或进入后台停止定时刷新，重新打开或回到前台会核对状态。自动刷新与「刷新核对」都保留未保存的过滤指示；读取失败保留上次记录，不显示为空列表。写入或分析结果未明时，仍需手动「刷新核对」，不会自动重发或重跑。
5. 可在承接会话中针对提醒明确说“不喜欢这条短信，少提醒这种内容”。助手使用受限 `feature` 工具沿服务端消息来源读取原始内容，将反应或评论保存回短信功能。反馈不写全局记忆或普通智能体规则，也不把一次不喜欢变成永久屏蔽。

对带来源消息的气泡点赞/不喜欢和评论，功能下一轮会按消息关联读取当前有效例证；撤销、编辑或删除按最新结果读取。绑定更换不改写旧消息来源。重置聊天删除该聊天的气泡反馈与关联，不删除功能本身的原文、逐条反馈或偏好，也不恢复被清除的消息。

既有普通智能体的通用信息后台数据与 API 保留，不自动迁移、删除或接管为短信功能。已开启的旧后台仍按原智能体处理；其只读 `information` 工具只查询本智能体。独立功能使用专用入口和受限来源工具，不因此开放任意跨智能体文件访问。

## 重置与删除智能体 {#reset-and-delete-agents}

### 重置当前会话 {#reset-current-session}

1. 长按目标智能体头像→「会话管理」→「重置当前会话」。
2. 核对对话框中的目标智能体。
3. 默认重置会停止当前运行，清空该智能体私聊历史、该成员在「全部」中的讨论和显示记录、消息反馈、未完成审批、Dream 整理游标、最近整理结果与待决建议，并开启全新会话；智能体规则、技能开关、Dream 配置、私有工作区文件、信息后台设置、原始信息、执行记录和偏好备注会保留。
4. 如需同时删除该智能体绑定的定时任务与网页监控，勾选「同时清理此智能体下的定时任务与网页监控」。默认不勾选，任务和监控会转绑到新会话。
5. 点击「确认重置」。成功后显示「会话已重置」，可开启全新对话。

被清空的聊天历史和消息反馈无法恢复。重置会取消尚未落盘的信息通知；历史发布关系仍可追溯，但旧会话反馈不会迁移为新的偏好例证。若网络结果未明，客户端会显示待确认并暂停发送；先点击「核对重置结果」，不要自动重试重置。

### 删除智能体 {#delete-agent}

1. 长按「全部」，进入「全局设置」→「智能体管理」。
2. 在要删除的普通智能体一行点击删除按钮。
3. 在确认弹窗核对名称、智能体 ID 与不可恢复的删除范围。
4. 点击「确认删除」，或取消而不提交。删除当前私聊对象后返回「全部」；删除其他智能体不改变原聊天。

::: danger 不可恢复删除
删除智能体会彻底清除该智能体的私聊历史、在「全部」中的讨论与显示记录、消息反馈、私有工作区文件、智能体规则、技能配置、Dream 配置与整理状态、信息后台数据，以及绑定的定时任务和网页监控。操作不可撤销，不会自动迁移到主智能体。Muse、新闻和短信内置成员不可删除；绑定功能的其他智能体须先在对应功能成员的设置中显式更换承接智能体，否则删除会被拒绝，不会自动回退主智能体。只想清空对话时使用「重置当前会话」。
:::

删除请求结果未明时，先刷新智能体列表核对，不要重发删除请求。删除成功后，之后使用相同 ID 新建智能体也不会恢复旧历史。
