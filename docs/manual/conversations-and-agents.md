# 对话与会话

Pi Muse 只有一个助手身份。会话用于分开不同话题的聊天上下文；所有会话共享工作区、身份资料和长期记忆。本文描述重构后的服务端语义；本次原生客户端适配、Android 链路与真实模型尚待统一验收，不把源码说明当作已发布 APK 的操作承诺。

## 前提 {#prerequisites}

按[快速上手](getting-started.md#connect-mobile-client)连接匹配版本的服务端。聊天需要已配置可用外部模型。客户端导航以完成适配并验收的版本为准。

## 会话列表 {#session-model}

「消息」显示默认会话与专题会话。默认会话 `main` 永远存在、标题固定为“默认会话”，不能删除，但可重置。专题会话由服务端创建稳定 id，可改名、重置或删除，缺省标题“新会话”。默认会话第一，其余按最近更新时间排列。

每个会话的正文、附件、工具结果、规则和技能覆盖独立；切换会话不把另一会话的历史自动交给模型。所有会话仍使用同一助手身份、实例模型、SOUL/USER 和长期记忆。长期记忆按需检索，不每轮全量加载。

## 发送与停止对话 {#send-and-stop-conversations}

选择会话后进入聊天。发送文字，或按[附件说明](files-and-approvals.md#send-attachments)随该条消息提交图片/文本。模型回复以流式显示，工具与审批呈现实际执行事实。

同一会话同一时间只有一个运行。停止绑定本次运行，不影响后续轮次；不同会话上下文独立。断开聊天流、显式停止、超时或服务关闭会取消所属运行及子调用，未决审批作废；已有副作用不回滚。通知连接断开不等于停止聊天。

发送或写操作结果未明时，先同步权威历史/状态，不自动重发。草稿、切页和后台行为依实际客户端版本核对，不承诺进程终止后的继续执行。

## 消息反馈 {#message-feedback}

已保存的用户/助手消息可喜欢、不喜欢、撤销反应以及增删改评论；正在生成的消息和工具结果不可反馈。喜欢/不喜欢互斥，评论去首尾空白后 1–4000 字符。

反馈绑定公开会话、内部 pi 会话与消息 id，独立保存原始操作事件，不改变聊天版本、不触发模型或训练。重置后旧内部身份不能继续写反馈。写入超时或结果未明先回读确认；不自动重试。

## 会话规则与技能 {#session-rules-and-skills}

会话规则保存到该会话的 INSTRUCTIONS.md，下一轮重读，最多 20,000 字符；空串是明确清空。最后成功保存生效，不自动合并。规则不能增加工具、扩大路径或绕过审批。

技能文本是全局资产，启用覆盖仅影响当前会话，下一轮生效。`main` 的规则同时是短信过滤与新闻偏好的入口；不会把 main 规则自动加进专题会话。

## 新闻与短信 {#background-services}

新闻是后台 RSS 与推荐管线，阅读见[新闻](news.md)。短信是实例全局管线，首次默认关闭；后台分析重要短信后，系统通知直接写入默认会话历史，不额外启动一次主聊天模型回复，专题会话不接收。静默或失败不会制造通知。

短信采集依赖 Android 原生模块、系统权限、功能启用与应用进程存活；不承诺进程终止后采集或操作系统推送。导入/执行结果未明先核对条目和处理记录，不自动重发或重跑。

## 子代理 {#subagent}

助手可调用 `subagent` 完成一次受限的 single/parallel/chain 工作。它只有内存上下文、不创建会话或目录，使用相同工作区，结果返回父工具调用。它不能递归委派、排程、监控、登记独立活动或修改会话指令；角色只收窄权限。文件修改仍逐次人工审批，父停止会取消子执行。

## 重置与删除 {#reset-and-delete-sessions}

### 重置当前会话 {#reset-current-session}

确认目标和不可恢复范围后再提交。重置停止当前运行，取消待审批，清空聊天 JSONL 和消息反馈并换新内部 pi 身份。公开 id、标题、规则、技能覆盖和共享工作区保留。可选同时清理该会话的任务与监控，缺省保留。

默认会话也可重置。重置不删除新闻、短信、全局记忆或全局 Dream 配置。结果未明先回读历史和会话列表，不自动重复重置。

### 删除专题会话 {#delete-session}

::: danger 不可恢复
删除专题会话会删除其历史、消息反馈、规则、技能覆盖和相关任务/监控。默认会话不可删除。唯一工作区、新闻、短信、身份和记忆是全局内容，不随专题会话删除。
:::

删除前明确确认；结果未明先刷新列表核对。已删除会话不能被迟到的消息、停止、反馈或通知复活。需要新话题时重新创建会话，不尝试复用已删除的 id。
