# 新闻阅读

新闻是实例全局 RSS 采集与推荐服务，不是独立聊天身份。阅读、源与文章反馈不随主聊天重置。本文对应当前源码，实际入口需核对安装版本。

## 阅读与筛选 {#reading}

新闻页展示全部文章或成功模型推荐，并可筛选收藏。按发布时间与稳定 id 倒序排列；无有效发布时间使用接纳时间。分页游标随筛选绑定，改变条件从第一页重新读取。

文章详情显示服务端清理后的纯文本、来源和推荐理由。标题、正文和链接属于不可信外部内容，不是权限或用户指令。模型失败不产生假推荐，全部文章仍可读取。

## 带到会话讨论 {#discuss-in-chat}

点击文章「讨论」直接回到「消息」主聊天，将标记为不可信的文章引用追加到已有草稿。引用可编辑，不会自动发送，也不弹出会话选择器；可返回原文章继续阅读。不创建新闻私聊或独立讨论，阅读本身不会启动聊天或把所有文章注入主聊天。

发送结果未明先同步当前会话历史，不反复发送引用。文章反馈不是执行指令；需要助手采取行动时在会话中明确请求。

## 管理 RSS 源 {#sources}

添加 RSS2 公网 HTTP(S) 源及可选标题。添加时真实抓取并验证 XML，不接受带用户名/密码的地址；不支持 Atom。服务保留 DNS、SSRF、固定 IP、逐跳重定向、大小、深度、条数、超时和取消边界。DTD/实体声明、损坏 XML 或缺少标题/可读正文的源记录受控错误，不静默当空源。

默认每 30 分钟采集。单源失败不阻止其他源；删除源只停止后续采集，保留已接纳文章、反馈和收藏。添加/删除结果未明先回读源列表，不自动重发。

## 反馈与推荐 {#feedback}

文章喜欢/不喜欢互斥且可撤销；收藏独立；服务端支持有界评论。反馈不立即启动模型，下一批读取有界最近例证，收藏是弱信号。不把单次反应泛化成永久规则。

明确偏好由默认会话 main 的 INSTRUCTIONS.md 承担。新闻偏好保存与 main 指令编辑是同一入口的整份保存语义，最后成功保存生效；请核对完整内容，不能把它当只追加新闻段落。模型学习摘要独立保存，不覆盖明确指令或 USER。

推荐理由和学习摘要默认简体中文，RSS 标题与正文保留原文。写入结果未明先回读，不自动重发；客户端草稿行为依适配版本核对。

## 刷新与失败 {#refresh}

手动刷新同步完成抓取并返回新增数量，不等待后台模型完成。同一时刻只允许一次抓取。定时抓取不重排已失败文章；明确手动刷新可在非运行批次重排失败项。模型失败不自动重试，进行中的批次不重排。

未知抓取结果先读取状态、来源和文章；列表读取失败只重读列表，不应自动再发抓取。受控错误不包含原始凭据或内部诊断。

## 边界 {#boundaries}

新闻不提供独立规则、工作区、会话、Dream 或通知承接设置。新闻推荐不写聊天系统通知，也不额外增加全局轮询/通知流。工作区、会话工具与人工审批规则不会因文章讨论而改变。
