# 客户端 Agent 与 Session 接入边界

本文只说明客户端状态归属；精确请求、响应与事件以当前 `src/http/contracts/` 和运行实例 `/docs` 为准，不另维护迁移字段表或兼容接口。

## 统一目录与核心能力

`/api/agents` 是唯一智能体目录，包含主智能体、普通智能体、新闻与短信。目录中的 `extensions` 表示附加业务与专属视图，不决定是否有聊天、规则、技能、私有文件或 Dream。客户端不再维护另一份成员身份目录。

稳定 `agentId` 是配置、私有文件、后台任务与通知绑定的归属。`sessionId` 是当前私聊的 PI 会话标识；重置后必须用服务端返回的新标识替换旧会话。群组不是智能体，群聊讨论也不是成员的普通私聊。

## 写操作与恢复

- 添加智能体先显式创建；结果未明时按原 ID 回读目录，不生成第二个 ID 自动重试。
- 历史读取与迟到停止不能创建智能体；历史为空不证明智能体存在。
- 重置清理当前聊天、讨论、反馈及关联审批，保留规则、技能和私有文件；调度是否删除由用户选择。删除才级联清理目标私有文件和归属任务。主智能体与内置扩展智能体不能删除。
- 切换智能体隔离草稿、历史、运行和异步回执；旧请求不得更新新智能体界面。结果未明先核对权威状态，不自动重放写操作。
- 新闻与短信专用 facade 固定业务 owner；通知承接可绑定任意已存在智能体。绑定不迁移原始数据，也不合并模型上下文。

## 当前协议与旧数据

当前调用方只使用 Agent 字段和 `agent` 工具，不保留 Space/Thread 接口、别名或读取器。实例身份资料、Dream 与运行状态分别使用当前独立入口，避免把身份快照误当智能体目录。

旧实例包含持久化字段、私有文件路径、指令用途标题和通信 marker 的差异，不能只改目录名。服务发现旧私有根时在初始化写入前拒绝启动；真实数据转换需要停服备份并另行确认。本模块只在新建隔离实例验收，没有修改真实实例数据。
